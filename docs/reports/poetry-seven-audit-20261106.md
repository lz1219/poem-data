# 诗词样板：系年状态与旧背景核查

2026-11-06，对 11 篇诗词阅读样板比对线上编辑库、线上作品文件和本地精选数据。发现六篇线上将仅以年份数字充当引文的系年标为已采信，作品 certainty 为 confirmed 或 probable；本地对应记录已标为 pending／unknown。年份数字不是可定位史料原句，状态不应由与作年字段相同自动推出。

本批同步《春望》《登高》《早发白帝城》《赠汪伦》《黄鹤楼送孟浩然之广陵》《独坐敬亭山》六篇的待核状态，保留原有年份、证据、作品和系年 ID；背景中缺少核实依据的准确年份与情节改为待核或可由诗题、正文支持的描述。此操作不代表否定相关常见系年，后续取得可定位证据后仍需逐篇核实。

《念奴娇·赤壁怀古》旧背景称作者误以为黄州赤鼻矶即古战场，旧赏析又称作者明知未必是，互相矛盾；仅凭词句“人道是”不足判断作者实际想法。改为如实描述词句与待核状态，保留推测字段但限定其结论边界。作为现代解释线索，教育部资料将黄州赤鼻矶与古战场区分，不能据此证明作者的主观判断：[《念奴娇·赤壁怀古》相关材料](https://www.moe.gov.cn/ewebeditor/uploadfile/20110310155511857.pdf)。旧版完整数据库记录与原作品文件均已备份。
