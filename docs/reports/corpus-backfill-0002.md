## 重现与下一批

工具默认离线预览，明确apply才写库，verify只读，rollback受依赖保护；实际凭据与原件缓存放仓库外：

```powershell
python scripts/backfill_shiji.py preview --cache <原件缓存> --permission-sha <许可响应哈希> --output <预览报告>
python scripts/backfill_shiji.py apply --cache <原件缓存> --permission-sha <许可响应哈希> --credentials <本地凭据文件> --backup-dir <仓库外备份目录>
python scripts/backfill_shiji.py verify --cache <原件缓存> --permission-sha <许可响应哈希> --credentials <本地凭据文件>
```
