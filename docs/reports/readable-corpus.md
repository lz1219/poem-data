# 可读性优先与旧脚本清理

R-16、D-3。用户将可读性放在首位，要求优先整理公开TXT并删除没用的历史脚本。此批在现有Django和零构建前端改造，不增加npm依赖；整体识典/典读式馆藏、专题与译注建设仍进行中。

## 阅读行为

- Python采用[官方OpenCC](https://github.com/BYVoid/OpenCC) 1.4.2，t2s.json生成简体阅读视图，记录转换器、配置和原文SHA-256；原库正文、版本、来源偏移与既有引用不改。
- 默认简体阅读、收起夹注；可切原字阅读和完整原录、显示夹注、调字号、前后卷及卷目选择。原录可逐字复制；阅读文字单独复制，避免把转换文本当原始底本。
- 只对明确来源页的版式硬换行/空白和夹注双行斜线作阅读排版；旧段落的换行保留。括号分组不确立注者归属。未释编码字在阅读版以□提示，原录保留标记，不猜字。
- 正文居前，版本与来源详细信息按需展开；待校、未标点、未释字和组件边界提示保留。来源页不是自然段，原偏移仍指向原录。
- 现有书目默认已有标点优先，可筛选已有标点；书名提供简体检索，正文按原输入及OpenCC简繁候选查询，百分号仍为字面值。不是所有异体和跨行词的全召回保证。
- 没有OpenCC的旧部署明确禁用简体转换，原字和原录可继续读。静态策展站照原范围运行，完整语料阅读仍使用Django。

没有用AI补写原文、翻译或猜标点；后续优先整理可追溯的现成标点TXT。有注本、原版及影像并列用于研究，不让最难读的版式成为公众阅读的唯一入口。

地图删除`_add_appreciations.cjs`、`_add_meanings.cjs`、`_add_missing.cjs`、`_add_jiangjie.cjs`及`_merge_works.cjs`。这些旧工具直接写生成物或绕回生成器；现在统一改poem-data JSON并emit-atlas。执行契约、NOTICE及历史规格入口同步，署名与许可保留。没有把废脚本换目录继续堆放。

实际采集、导入、备份、回滚、来源哈希核验与测试继续保留。未处理的贵州/龙场旧改动保持原样。
