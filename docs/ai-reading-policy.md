# AI译注与段落阅读方案

状态：2026-11-04项目持有人逐项确认，R-13首期执行依据。卷一91个来源正文块均已有AI未审译注，人工审校及重点赏析仍待推进，实际范围见[最新批次](reports/ai-reading-0008.md)。长期定位见[项目总纲](project-charter.md)，共同内容标准见[编纂规范](editorial-policy.md)。

## 已确认的方向

现有馆藏整体可读与重点典籍完整达标都重要。读者选中一句或一段后，能够看到对应注释和译文；重点篇章、名段另有赏析，延伸阅读作为后续增强。先建设文献站，再推进地图应用。来源补全、版本核实和阅读结构整理持续进行。

| 决定 | 首期执行方式 |
|---|---|
| AI生成时机 | 整理阶段批量生成、检查后入库；网站读取已保存内容 |
| 网站调用AI | 首期不接实时生成，也不采用首次访问生成后缓存的方式 |

## 译注、校记与AI推测的区别

AI译文、拟释和赏析是本站解释层，附生成与审校状态，可以在相应段落阅读区展示；来源已有的编者校记、古注和古人评点按各自出处与身份独立保存。AI不得代署古人、伪造引文或把解释写回来源正文。

涉及史事、因果、作者心理等研究假说时，仍执行独立AI推测规范，附真实依据、反证检索及替代解释，不进入确定事实或默认地图路线。阅读区显示AI译注，不构成将研究推测混入事实的许可。

外部事实须有可定位材料；原句语义解释须指明所据原句。没有核到字书、古注或论文时不得编造出处；可以标为本站AI拟释并说明语境依据和不确定性。来源使用条件不清的材料，不因AI改写就自动获得公开权限。

## 内容组织与原文修订

复用现有全文库、版本、卷篇、段落及来源关联，不另建平行全文库。精选作品JSON与整书语料仍遵守各自发布职责，全文译注不为地图展示重复塞入精选JSON。

译注逻辑记录至少关联：书目、版本／固定来源修订、卷篇、段落稳定标识、所据原文哈希；注释另记录被注原字及位置。来源页或标题块不能自动视为自然段，卷一先复核段界，标题不计作待翻译段落。跨自然段选文的交互规则留待实施规格明确，首期不承诺任意选区独立解释。

译文、注释、赏析分别保存，允许分别缺失或审校；重点清单注明入选范围与理由，不根据AI评分自动认定“名句”。延伸内容先作为后续范围，不设凑数指标。

每批记录生成方式、实际可得的模型和版本、时间、任务／提示模板版本、所用原文及参考来源、程序检查结果与修订关系。缺失信息如实记缺；AI自检或其他模型复核不标成人工审校。纠错记录处理决定和新修订，人工审校记录人员、时间及实际范围，保留AI参与历史。

换源或原文改变时检查译注对应关系。旧译注不能自动继承到新正文，也不能继承“已审校”状态；已公开修订保持可引用，失配内容退出新正文默认展示并说明待复核。具体存储契约在实施前核对现有结构后增量制定。

## 批次与公开门槛

固定原文与来源 → 复核段界及重点清单 → 批量生成候选 → 程序检查 → 按批次保存 → 真实阅读验收 → 按现有确认流程发布。

程序检查至少拦截：无有效段落／版本关联、原文哈希失配、注释越界或被注词不符、漏段／重复、译文和大意混用、必需来源或生成记录缺失、AI标识缺失、生成内容冒充古人评点。检查结果说明覆盖范围；结构通过不证明译文语义正确、注释充分或史实确证。

失败项留在候选区，报告原因；读者侧保持“译注待补”或实际待核状态。允许未人工审校内容公开，是内容准入决定，不是自动部署许可：批次和网页仍遵守既有发布确认纪律。

生成所需的模型、调用方式、费用／额度、批量大小尚未确定。网站不实时接AI，不等于批量生成无需模型；实施时评估可用工具和生成通道后确定，不预先假设付费API或新增依赖。备份、转换及生成在写事务外，入库继续遵守[性能和服务器规范](corpus-operations.md)。

## 首要任务与验收

看板排序唯一真相在地图仓库docs/backlog.md。2026-11-05用户调整为先设计诗词名篇阅读页面及基调；R-13《资治通鉴》卷一试点及全库核查、补源继续保留后续队列。

1. 核对卷一现有结构、原句、段界和来源，区分正文、标题与校记，建立准确分母。
2. 评估已有字段、脚本与生成工具，确定最小内容契约、生成通道、检查和失败处理；适合重建的脚本可重建，避免逐书补丁堆积。
3. 先验证短记事和“臣光曰”等议论的代表段落，再覆盖卷一正文；重点清单另行维护。
4. 批量生成、检查并入库，保留来源、原文关联及生成修订记录；不猜补未解决内容。
5. 真实验证选句到所属段落、完整译文、相关注释定位、原字／简体切换、待补与AI标识、纠错入口、手机阅读，以及入库读回和修订失配拦截。

验收逐项报告正文译注覆盖、失败／待补、赏析清单覆盖及人工审校范围，不用字段非空率冒充学术质量。卷一试点当前真实进展见[最新批次](reports/ai-reading-0008.md)，不能将来源块数字等同全卷译注及审校完成。
