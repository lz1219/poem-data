# 行迹人物清单与计划

> 数据依据：`corpus_poem` 3,879 位作者 × CBDB 592,350 条任职记录。
> 测算脚本：`_verify/journey-candidates.cjs`（按语料高频作者 × 任职条数排序）

## 一、行迹的三条数据路径

一条行迹 = 若干站点，每站需要 **年 + 地 + 事 + 出处**。三种取法：

| 路径 | 依据 | 适用 | 成本 |
|---|---|---|---|
| **A 仕宦驱动** | CBDB 任职记录（年区间 + 官职 + 任职地） | 有仕宦记录者 | 低（可半自动） |
| **B 年谱驱动** | 年谱、史传 | 无仕宦记录但有事迹者 | 中 |
| **C 诗题驱动** | 作品题名与诗中所涉地名 | 诗人，作品系年可考者 | 高（须逐条判断） |

**杜甫是 C 路径的样板**（CBDB 只有 3 处任所，靠年谱+诗题做出 11 站）。
**白居易是 A 路径的样板**（CBDB 27 条仕宦 → 11 站）。

## 五、分批计划

| 批次 | 内容 | 产出 | 前置 |
|---|---|---|---|
| **B1** | 欧阳修、杜牧 | +2 条行迹、约 +20 站 | 无 |
| **B2** | 韩愈、王维、岑参、高适 | +4 条、约 +40 站 | 需先补 person 档案 |
| **B3** | 元稹、刘禹锡、李商隐、韦应物 | +4 条、约 +40 站 | 同上 |
| **B4** | 余下任职 ≥8 条者 | +6–8 条 | 同上 |

**每批的统一流程**：

1. 补 `data/persons/<key>.json`（生卒、字号、别名、CBDB id）
2. 从 CBDB 取任职记录（年区间、官职、任职地）
3. 合并同年同地记录 → 站点；补「事由」叙述与出处
4. 无仕宦覆盖的年份，用年谱/诗题补（C 路径）
5. 跑 `export_json --check`、`emit-atlas`、站点校验

## 六、每条行迹的验收标准

- 站点 6–12 个，每站有 **年、古地名、今地名、事由、出处**
- 至少 3 站带引文（作品原句）
- 导语一段（含出处）
- 站间承接语按需（证据不足处写承接语，不造站）
- 通过 `manage.py crosscheck_career` 交叉校验，矛盾处须在 `basis` 里说明

## 七、工作量估计

- A 路径（仕宦驱动）：每位 2–3 小时（取数、合并、写叙述）
- C 路径（诗题驱动）：每位 6–10 小时
- 34 位全做 ≈ 80–120 小时；按批次推进，每批 4–6 位
